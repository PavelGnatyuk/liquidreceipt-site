## About Receipt

Receipt turns paper receipts into organized PDFs with automatic intelligent data extraction. Perfect for business trips, vacation expenses, and personal finance tracking.

### Key Features

- 🧠 **Smart OCR** - Auto-extracts merchant, date, total & line items using Apple Vision
- 📁 **Folder Organization** - Organize receipts by trip, project, or category
- 💱 **Multi-Currency** - 7 currencies (USD, EUR, GBP, RUB, ILS, GEL, BYN) with exchange rates
- 📤 **Export Reports** - Combined PDF & CSV for expense reports
- 🔍 **Powerful Search** - Find by merchant, amount, or any text
- 🎤 **Voice Comments** - Add notes by typing or dictation
- 📲 **Share Extension** - Import from Files, Mail, Safari, Photos
- 🔒 **100% Private** - All data stays on your device
- 🚫 **Free Forever** - No ads, no subscriptions, no in-app purchases

### Technical Details

- **Platform:** iOS 26.0+
- **Frameworks:** SwiftUI, VisionKit, Vision, PDFKit, SwiftData, Speech
- **Design:** Liquid Glass with Sepia theme
- **Storage:** Local only (SwiftData)
