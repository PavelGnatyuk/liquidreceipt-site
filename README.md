# Receipt - Website

This repository contains the support website for the **Receipt** iOS app.

## Pages

- **privacy_policy.html** - Privacy Policy
- **support.html** - Support page with FAQ and contact information
- **terms.html** - Terms & Conditions

## About Receipt

Receipt is a simple, privacy-focused receipt scanner for iOS. All data is stored locally on your device - we never upload or access your receipts.

### Key Features
- 📷 Quick receipt scanning
- 🔒 100% private - all data stays on your device
- 📴 Works completely offline
- 🚫 No ads, no tracking, no cloud
